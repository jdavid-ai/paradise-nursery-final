# e-plantShopping

## Descripción del proyecto

**e-plantShopping** es una aplicación web de compras de plantas desarrollada con React. El proyecto presenta una tienda virtual de plantas donde los usuarios pueden explorar diferentes plantas y gestionar los productos seleccionados mediante un carrito de compras.

## Funcionalidades

* Página de inicio.
* Catálogo de plantas.
* Navegación entre las secciones de la aplicación.
* Carrito de compras.
* Selección y gestión de productos.
* Interfaz web para una tienda de plantas.

## Tecnologías utilizadas

* React
* JavaScript
* React Router
* Vite
* HTML
* CSS
* Git
* GitHub
* Vercel

## Secciones principales

### Inicio

Página principal de la aplicación Paradise Nursery.

### Plantas

Sección donde los usuarios pueden visualizar las plantas disponibles.

### Carrito

Sección donde los usuarios pueden gestionar las plantas seleccionadas para su compra.
